## Publicação com GitHub Pages

O site é servido pelo arquivo `index.html`. O `README.md` é apenas a documentação do repositório: o GitHub não executa nele o CSS e o HTML de uma página completa.

Para publicar:

1. Crie um repositório chamado `SEU-USUARIO.github.io` (substitua pelo seu usuário do GitHub).
2. Envie `index.html` para a raiz do repositório, no mesmo nível deste `README.md`.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
6. Acesse `https://SEU-USUARIO.github.io/` após a publicação.

As imagens do portfólio estão incorporadas no próprio `index.html`; não é necessário configurar caminhos ou enviar arquivos de imagem separados.
